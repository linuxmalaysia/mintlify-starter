Welcome to **Elastic Stack on Podman** — an automated deployment toolkit that sets up Elasticsearch, Kibana, and Fleet Server using rootless Podman containers backed by security-hardened Wolfi images. Whether you are running a single Linux workstation, a multi-node VM cluster, or a Windows 11 machine with WSL2, this toolkit gives you a production-ready Elastic Stack with minimal manual effort.

## Get up and running in three steps

The fastest path from a fresh system to a running Elastic Stack takes just three steps. Follow these to verify your environment and launch your first deployment.

<Steps>
  <Step title="Install prerequisites">
    Ensure Podman 5+, `podman-compose`, and the required kernel tuning (`vm.max_map_count=262144`) are in place on your Linux or WSL2 host. See the [Prerequisites](/prerequisites) page for exact commands.
  </Step>
  <Step title="Run the setup scripts">
    Clone the repository, make the scripts executable, and run `./setup_elasticsearch.sh` followed by `./setup_kibana.sh`. Both scripts detect your OS, install any missing dependencies, pull the hardened Wolfi images, and start the containers automatically.
  </Step>
  <Step title="Access Kibana">
    Open your browser and navigate to `http://localhost:5601`. Retrieve your auto-generated `elastic` user password from `elk-wolfi/temp_credentials.txt` and log in to start exploring your data.
  </Step>
</Steps>
